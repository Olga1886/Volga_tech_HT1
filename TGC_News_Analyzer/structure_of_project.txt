TGC_News_Analyzer/
├── cli.py           # Основной скрипт приложения.
├── messages.html    # Пример HTML-файла с экспортированными сообщениями из Telegram (должен быть заменен на ваш файл).

├── output.csv       # Пример выходного CSV-файла с результатами анализа (создаётся после запуска).
├── README.md        # Описание проекта, инструкция по установке и использованию.
├── requirements.txt # Список зависимостей Python.
├── timeline.csv    # Пример выходного CSV-файла с таймлайном (создаётся при запросе таймлайна).
└── timeline.png    # Пример PNG файла с визуализацией таймлайна (создаётся при запросе графика).
